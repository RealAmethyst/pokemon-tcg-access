## Features
- the settings screen now speaks every switch the same way. The windowed, card hover and reduced effects switches read "on" and "off" like the accessibility ones do, using the game's own wording rather than the mod's, so they also follow your game language
- the settings screen works again, and now covers the game's new accessibility options. The August update replaced settings with a tabbed screen — Accessibility and General — and the mod was still reading the old one, which the game had switched off, so the screen was silent and you could get stuck in it. It now reads the tab strip and whichever tab you're in: sound, video and language under General, and under Accessibility the four options for reducing motion and visual effects (game board animations, card foil animations, front-end effects and battle effects), each with its name, description and current value
- updated for the game's July and August updates — every screen the mod touches was re-checked against the new game code, twice
- The game updater app is now also accessible.
- damage counters has been rewritten so they actually mirrors how the client talks to the server.
- booster packs speak their real names instead of just "pack"
- COLLECT ALL is now reachable in the middle of opening a pack
- the deck editor's new format switch button (added by the game's July update) reads as "Change format" plus the current format
- the reward collection screen now says "Rewards" before listing what you're about to collect, so a list of card names can't be mistaken for the contents of an unopened pack

## Bug fixes
- you can always leave a screen now. Escape is handled before anything else on the settings screen, so even if something goes wrong reading it, the screen can still be closed. Previously a failure anywhere in that screen swallowed your Escape as well and sealed you in
- fixed a crash-loop on the settings screen that silently ate every keypress. The mod was reading one of the game's own collections the wrong way round and threw an error on every single frame, which meant no key you pressed was ever looked at
- fixed the Settings panel losing everything but its back arrow. Opening settings a second time in the same session read out nothing but Back — and since Back was then the only thing there, you couldn't move down out of it either. Closing the panel deactivates it, and when you reopen it the game restores the controls underneath a frame later, by its own design; the mod was reading the panel inside that gap. It now waits for the panel's real contents instead, for exactly as long as the game takes, and gives up waiting when the game reports the panel has finished appearing so it can never sit there in silence. The first open of a session was never affected, which is why this only showed up on a second visit
- fixed the Battle Pass going silent after the August update. Focusing the daily quests or the rewards list read out nothing at all, even though the arrow keys were still moving the selection behind the scenes and enter still claimed the right reward — so you could collect things blind, without ever hearing what they were. COLLECT ALL was silent in the same way. The August update moved the game's reward, item and currency descriptions into a new code library, and the mod was still looking in the old one, so every routine that builds a reward label failed the instant it was asked to run. Navigation never touched those descriptions, which is why it kept working while the speech disappeared
- fixed the deck editor's card list going silent, and the crash when changing the card filter. The August update changed the way the game represents a stack of cards, and the mod's copy of that arrangement became structurally invalid — so reading a card out loud, inspecting one and picking one up all failed on contact, and on the filter path the same fault took the game down with it. Both are fixed
- fixed a separate crash lurking in the deck editor's filter. When you change the filter, the game empties its card list and refills it, and only reports the new total a moment later; the mod trusted its own remembered total across that gap, and a keypress landing in that window could divide by zero inside the game's own code and take it down. The mod now asks the game for the live count every time it steps through the list, so there is no longer a gap to land in. This one was not new in August — it had been waiting there
- fixed damage counters being lost. When an attack or ability had you place or move several counters — Dragapult ex's Phantom Dive, Munkidori's Adrena-Brain and the like — everything before your last drop was quietly erased from what got sent to the server. On screen it looked right, but the opponent's damage didn't match afterwards. This was also what froze the tutorial's damage-moving lesson: the opponent survived damage that looked lethal, so the tutorial waited forever for a knockout that never came. The whole damage flow was rebuilt on the game's own bookkeeping, and that lesson now completes properly
- in the tutorial's damage step, your first enter on the target now works
- the mod can no longer enforce tutorial rules in normal matches. A rare account state could make a ranked match refuse every action with "the tutorial isn't ready for that yet", locking the whole game. The mod now follows tutorial restrictions only in matches the game itself has set up as tutorial-run — in any other match they simply cannot trigger, whatever state the tutorial system is in
- fixed pack opening reading the previous pack's card: with several packs to open, pressing down on a new, still-sealed pack read out the stats of the last card from the pack before. A sealed pack now stays quiet until a card is actually revealed
